# Cloud environment Node check, 2026-10-08

**Verdict: no.** Bare `node` is v22.22.0, `.nvmrc` asks for 24.11.1. The SessionStart hook ran and
pointed `/usr/local/bin/node` at v24.11.1, but `/opt/node22/bin` comes earlier in `PATH`, so a plain
`node`, `npm` or `npx` never reaches those symlinks.

```

$ npm -v

lrwxrwxrwx 1 root root 40 Oct  8 00:51 /usr/local/bin/node -> /opt/nvm/versions/node/v24.11.1/bin/node
lrwxrwxrwx 1 root root 39 Oct  8 00:51 /usr/local/bin/npm -> /opt/nvm/versions/node/v24.11.1/bin/npm
lrwxrwxrwx 1 root root 39 Oct  8 00:51 /usr/local/bin/npx -> /opt/nvm/versions/node/v24.11.1/bin/npx

24.11.1
```

Why they disagree:

```
$ echo $PATH
/nix/var/nix/profiles/default/bin:/root/.local/bin:/root/.cargo/bin:/usr/local/go/bin:/opt/node22/bin:/opt/maven/bin:/opt/gradle/bin:/opt/rbenv/bin:/root/.bun/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin

$ type -a node
node is /opt/node22/bin/node
node is /usr/local/bin/node

$ /usr/local/bin/node -v
v24.11.1
```

## Hook

```
$ cat ~/.claude/settings.json
{"hooks":{"SessionStart":[{"hooks":[{"type":"command","command":"/usr/local/bin/use-repo-node","timeout":120}]}]}}

$ ls -l /usr/local/bin/use-repo-node
-rwxr-xr-x 1 root root 828 Oct  8 00:51 /usr/local/bin/use-repo-node
```

At session start the context carried: `SessionStart:startup hook success: Node v24.11.1 from .nvmrc`.

Running it by hand:

```
$ /usr/local/bin/use-repo-node
Node v24.11.1 from .nvmrc
[exit 0]
```

The message is accurate about `/usr/local/bin/node` (the script prints `$(/usr/local/bin/node -v)`), but
it doesn't reflect what a bare `node` resolves to, so it reads as a pass while the shell still runs
v22.

## Suggested fix (not applied)

Have the setup script or hook put the nvm bin first, for example by also replacing
`/opt/node22/bin/{node,npm,npx}` with links to the `.nvmrc` version, or by writing a `PATH` with the
nvm bin ahead of `/opt/node22/bin` into the environment (`CLAUDE_ENV_FILE` in the SessionStart hook).
The hook's success line should then report `node -v` from a bare lookup, not from
`/usr/local/bin/node`.
